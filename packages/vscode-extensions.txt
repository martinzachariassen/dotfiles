# eamodio.gitlens was removed 2026-08: VS Code's built-in git/blame/timeline covers
# what was actually used, and the rest was noise.
# 15 extensions were removed 2026-08: unused in practice. Uninstalled by hand first,
# then dropped here — the mirror is 1:1, so leaving them listed would have reinstalled
# them on the next apply. By theme:
#   Python      ms-python.python, ms-python.debugpy, ms-python.vscode-pylance,
#               charliermarsh.ruff — no Python is written on these machines. The
#               [python] block now just opts out of formatOnSave (Prettier, the global
#               default formatter, cannot parse Python and would error on every save).
#   IaC / k8s   hashicorp.terraform, hashicorp.hcl,
#               ms-kubernetes-tools.vscode-kubernetes-tools, tim-koehler.helm-intellisense
#               — the CLIs stay in Brewfile.work; only the editor integrations go.
#   Other       sonarsource.sonarlint-vscode (ErrorLens covers the diagnostics that were
#               read), humao.rest-client, genuitecllc.codetogether, wmaurer.change-case,
#               vivaxy.vscode-conventional-commits (the commit-msg hook and CI enforce
#               the convention; this was only an input popup),
#               vscjava.vscode-spring-initializr (scaffolding, used once).
#   bierner.markdown-mermaid was the only one of the four mermaid extensions that
#   injected rendering into VS Code's *built-in* markdown preview, which
#   workbench.editorAssociations makes the default for .md. Accepted: mermaid fences no
#   longer render there. The three kept mermaid extensions supply syntax highlighting
#   and their own preview panels instead.
# GitHub Copilot is deliberately absent: github.copilot was deprecated in VS Code

# extension since 1.116 — built-ins never appear in `code --list-extensions`, so
# there is nothing here to track or prune.
