# Resources

**Reference material** — things you might want again. No ownership, no
deadlines.

- `41 Tech/` — code snippets, runbooks, language notes, architecture patterns
- `42 People/` — colleagues, friends, 1:1 history *(new note → `person` template)*
- `43 Reading/` — books, articles, papers *(new note → `reading` template)*

For a general note that doesn't fit a type, press `⌘⇧I` and pick `note`.
See [[Vault Guide]].
