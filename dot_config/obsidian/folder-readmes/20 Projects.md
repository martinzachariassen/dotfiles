# Projects

**Active, deadline-bound work** — a clear outcome and an end date. When it's
done, move it to `50 Archive/`.

- **Create:** make a new note here and the `project` template runs
  automatically (prompts for name, `domain`, and `priority`).
- **Flat by design:** no work/personal subfolders. The `domain: work | personal`
  property splits them in dashboards instead.
- **One folder per project** (e.g. `platform-migration/`) with the project
  note as its index; keep meetings and assets alongside it.

If it has no finish line, it's an **Area** (`30`), not a project. See [[Vault Guide]].
