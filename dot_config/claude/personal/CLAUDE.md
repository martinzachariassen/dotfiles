# Claude Code — personal profile

@~/.config/claude/CLAUDE.shared.md

The **personal** profile (chezmoi `profile = personal`). The shared base above
holds who I am and how I code; the rest of this file is how Claude Code should
operate on personal machines.

## Operating posture

- **Autonomy: high.** Make the change, run the relevant check, report the
  result — don't stop at a proposal for routine work.
- **Experimentation: encouraged.** Free to try newer language features,
  libraries, or patterns worth a look. Prototype-friendly — momentum over
  ceremony unless I say otherwise.
- **Verification: light.** Run the narrowest useful check — a targeted test,
  build, or typecheck. A green focused test is enough for a small change.
- **Git:** committing straight to `main` is fine on small solo repos; use
  branches/PRs only when I ask or the repo already works that way.
- **Dependencies:** fine to add one when it clearly helps — mention it, no need
  to ask first.
- **Scope:** small opportunistic cleanups alongside a change are welcome here.

## Teaching

When I'm working with something unfamiliar, a short *why* — the reasoning or
tradeoff behind an approach — is welcome here, even though the shared base says
keep it concise. Personal projects are partly for learning.
