# Areas

Everything you're actively working or maintaining, split by **domain**, not
by type. A project, an ongoing responsibility, a reference note, a person, or
something you're reading all live here — the `type` property (not the
folder) says which.

- `Work/` — role, team, projects, dev references, work contacts
- `Personal/` — health, finances, home, relationships, personal projects
- `Learning/` — disciplines you're cultivating, reading list, courses

**Create:** QuickAdd's **New project** / **New area** / **New person** /
**New reading item** / **New meeting** commands (`⌘P` or the mobile toolbar)
each prompt for a domain and file themselves into the matching folder.

Finished or retired? Move it to `20 Archive/`. See [[Vault Guide]].
